# ADR-0046: 終わったチケット(done・dropped)に話しかけられたら、メモを書かず既定のブランチの読むだけの場所で答える

- 状態: 提案
- 日付: 2026-11-14
- チケット: #24

## 背景

メンバーとの会話(ADR-0045)は、今のチケットのセッションで答え、伝えたことをチケットのメモに書き足し、チケットのブランチで作業場所を用意する。チケットが done・dropped になったあとも「あれはどうなった」と聞かれるが、そのままの形で答えると、次の不都合が出た。

- 終わったチケットのメモが書き足され、もう読まれないメモが増える。
- チケットのブランチはすでに消えている(merge のあと)ことがあり、取り出しに失敗する。
- 開発の作業場所(`<番号>-dev`)を既定のブランチに切り替えてしまい、取りやめを戻して再開したとき、前の作業が無い場所で続きになる。

## 決定

- 現在のチケットが done・dropped のときは、**メモを書き足さず**、チケットのブランチも取り出さない。
- 答えるための作業場所は、**ブランチなし(既定のブランチ)で、会話専用の読むだけの場所 `<番号>-chat`** として用意する。ブランチが消えていても失敗しない。前の起動の残りは捨てて既定のブランチに合わせる。
- **開発の作業場所(`<番号>-dev`)には触らない**。取りやめを戻したときに、前の作業が残っている。
- 会話専用の場所は、ほかの作業場所と同じく、チケットが merge・取りやめで終わったあとに片付ける(ADR-0049)。

## 結果

- 終わったチケットについて聞いても、メモが散らからず、ブランチの有無で失敗しない。
- 再開できるチケットの作業が、会話で壊れない。

## 検討した別案

- **終わったチケットには話しかけられなくする**: 完了後の疑問(何を変えたか・なぜ取りやめたか)に答える場所が無くなる。
- **開発の作業場所を既定のブランチに切り替えて使う**: 取りやめを戻すと、前の作業が無い場所で続きになる。会話専用の場所を分けて避けた。
- **メモは書くが次の起動では読まない**: 書いても使われないメモがチケットに残るだけ。
