# ADR-0014: 設計書は作業場のリポジトリの docs/ に PR で置く

- 状態: 提案
- 日付: 2026-11-07

## 背景

アーキテクトが書く設計書の置き場所を決める必要がある。

## 決定

- 設計書はプロダクトの知識なので、作業場のリポジトリの `docs/` に PR で置く。Kuramoto を使わない人も読め、コードと一緒にレビューされる。
- 複数のリポジトリにまたがる設計は、主になるリポジトリに置き、他からリンクする。
- 方針やモデルの設定を「リポジトリに書かない」([ADR-0010](0010-role-policies-versioned.md))のは運用の話なので、これとは矛盾しない。

## 結果

- 設計の変更もコードと同じ手順(PR・レビュー)で残る。

## 検討した別案

- **Kuramoto の DB にだけ置く**: Kuramoto を使わない人から見えない。
