# ADR-0055: オフィスは「駅」と「路線」の路線図にして、種類ごとの流れ・連絡経路・答え待ちの質問を 1 枚に見せる

- 状態: 提案
- 日付: 2026-11-14
- チケット: #11(路線図にする)・#78・#91(ラベル・札の重なりの直し)
- 関係: ADR-0043(連絡経路)・ADR-0044(種類ごとの流れ)・ADR-0045(メンバーとの会話)

## 背景

オフィスは島ごとにメンバーが座る絵だった。種類ごとの流れ(ADR-0044)と連絡経路・質問(ADR-0043)ができると、「どの種類のチケットがどの島を通り、どこへ質問が飛ぶか」を、メンバーの絵とは別に 1 枚で見たくなった。

## 決定

- 床を**駅の列**(島・工程)にし、**種類ごとの路線**を、止まる駅を順に結んで描く。路線は駅の下の帯(駅の中)を通り、端で折り返す。開発より前の確認は申し送りの折り返しにラベルを出す(ADR-0044)。
- **連絡経路は点線**、**答え待ちの質問は封筒**で描く。動きは `prefers-reduced-motion` で止まる。保存前の経路の案は、床に重ねて見せる(編成の引き出しの「連絡経路」タブ)。
- 停車の番号は、受け口を 0 にして数える(ADR-0056)。丸の無い駅(島が無い・省略した工程)は「省略」と言う(ADR-0058)。
- メンバーを押すと、右の引き出しに、今のチケット・直近の手順・話す欄を出す(ADR-0045)。返事を書いている間は経過を出す。
- 生産性に、フロー効率の推移と、編成の版が上がった印(連絡経路 / 流れ / 島)を出す(ADR-0029 の追記)。
- 流れの線・札・ラベルが、下の段のメンバー(名札・吹き出し)に**重ならない**ことを、描画と e2e の矩形の交わりで確かめる(#78・#91)。駅の下の帯の最小の高さ(160px)と、帯の上端から最初の路線までの間(68px)は、その確かめで決めた値で、下の段に吹き出しが出るときは席の下を 56px 空ける。

## 結果

- 流れ・経路・質問・メンバーが 1 枚で見られる。編成の案の効果を、版の印と合わせて比べられる。
- 重なりを、見た目の確認だけでなく e2e で止められる。

## 検討した別案

- **種類ごとの流れを別の画面(図)にする**: メンバーの様子と離れ、見比べにくい。
- **メンバーの絵だけにする**: 流れと経路が見えず、編成を変える判断の材料にならない。
- **ラベルが重なっても気にしない**: 札が下の段のメンバーに隠れて読めなくなった(#78・#91 の不具合)。
