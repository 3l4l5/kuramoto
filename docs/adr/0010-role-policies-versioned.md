# ADR-0010: 方針とモデルは役割ごとに版で管理し、作業場リポジトリには書かない

- 状態: 承認
- 日付: 2026-11-07

## 背景

レビューや実装で重視してほしいことを調整したい。どのモデルで動かすかも画面から決めたい。

## 決定

- 役割ごとに「重視すること」(自由記述)・モデル・考える深さを設定する。ツールの使い方や報告の形などの基本指示は Kuramoto が固定で持ち、触れるのは「重視すること」の層だけ。
- 保存するたびに版が上がる。次に仕事を始めたメンバーから反映する。
- 保存先はプロジェクトの設定(Kuramoto 内)。作業場のリポジトリには何も書かない。
- 既定のモデル: 開発・レビュー・セキュリティは Opus 5.5 / high、QA は Sonnet 5.5 / medium、リーダーは Opus 5.5 / medium、アーキテクトは Opus 5.5 / xhigh。安いモデルに下げるかは責任者が決める。

## 結果

- 版ごとの効き目(指摘の割合・手戻り)を比べられる。
- 方針がリポジトリの外にあるので、Kuramoto を使わない人からは見えない。

## 検討した別案

- **リポジトリに Markdown で置く**: 版管理は楽だが、運用の設定がプロダクトのリポジトリに混ざる。
