# ADR-0031: 企画スタジオを止められるようにし、段階ごとの進み具合を見せる

- 状態: 提案
- 日付: 2026-11-12

## 背景

企画スタジオの担当は、オフィスを止めても動き続ける。担当が同じところを回り続けているように見えても、責任者には止める手段が無く(Kuramoto ごと止めても、起動し直すと続きから動く)、どれだけ起動してお金を使ったかも画面から分からなかった。

## 決定

- 企画スタジオに「止める / 再開する」を置く(設定 `plan_paused`)。止めると、動いている企画の担当の起動をその場で止め(ハーネスの中断)、新しい企画の依頼を取らない。止めた起動は失敗に数えず、依頼は待ちに戻す。再開すると、止めたところから続ける。オフィスのチームは別に動く。
- 同じ段階で、直近 1 時間に担当を `plan_loop_runs`(既定 10)回より多く起こしていたら、回っているとみなして自動で止め、理由を画面と会話に出す。
- 段階のタブに、起動の回数(通算・直近 1 時間)・使った額・エラーの数を出す。直近 1 時間の回数が上限に近づいたら目立たせる。会話の下に、その段階の最近の起動(時刻・担当・結果・かかった時間・エラー)を出す。

## 結果

- 回り続けている企画を、責任者が止められる。止め忘れても、上限で自動で止まる。
- どの段階にどれだけ起動とお金を使っているかが、その場で分かる。
