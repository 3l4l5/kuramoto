# ADR-0058: 言葉の決め — 「手すき」は「free」、「通過」は「省略」にそろえる

- 状態: 提案
- 日付: 2026-11-14
- チケット: #47・#49(通過 → 省略)・#90(手すき → free)

## 背景

同じことを指す言葉が、画面・担当への指示文・テスト・ドキュメントでばらついていると、画面を見た責任者と、指示文を読む担当・テストを書く人とで、意味が食い違う。

- **「手すき」**: 仕事を持っていないメンバー(島を名指ししたときに取る相手)。画面・指示文・ドキュメントで使っていた。
- **「通過」**: スマホのオフィスで、丸が無い(島が無い・流れから外した)駅の言い方。種類ごとの流れ(ADR-0044)・ADR-0008 の「省略」と同じ意味なのに、別の言葉だった。

## 決定

- 仕事を持っていないメンバーは **free** と言う。画面・指示文・テスト・ドキュメントをそろえる(#90)。
- 流れで丸が無い駅・飛ばす工程は **省略** と言う。スマホのオフィスの経路の説明は「(QA を省略)」とし、コードのコメントも「省略」にそろえる(#47・#49)。
- **既存の ADR の文は、当時の言い方のまま残す**(0023 の「手すき」など)。新しい ADR・ドキュメントは新しい言い方を使い、読み替えが要るときはここを参照する。
- 言葉を決めるときは、画面の文言・指示文・テスト・ドキュメントを同じチケットでそろえる(1 か所だけ直さない)。

## 結果

- 画面・指示文・テストで同じ言葉が使われる。
- 古い ADR には「手すき」が残るが、意味はこの ADR で分かる。

## 検討した別案

- **ADR も書き換える**: ADR は当時の判断の記録なので、言葉だけ変えると、いつ何と呼んでいたかが分からなくなる。
- **「手すき」のまま、画面だけ変える**: 担当への指示文との食い違いが残る。
- **「通過」を残す**: 工程を飛ばす意味の「省略」(ADR-0008・0044)と別の言葉が 2 つあり、混ざる。
