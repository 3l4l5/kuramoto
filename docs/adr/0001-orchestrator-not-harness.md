# ADR-0001: エージェントの実行環境は作らず、その上で動く交通整理の層として作る

- 状態: 承認
- 日付: 2026-11-07

## 背景

AI のエージェントをチームとして動かしたい。エージェント 1 体が考えてツールを使うループ(ハーネス)は、Claude Agent SDK などがすでに提供している。

## 決定

Kuramoto はハーネスを作らない。「いつ・誰を・何の情報を持たせて起こすか」を決める層(オーケストレーター)として作る。ただし、ハーネスの外側の殻として次は Kuramoto が持つ。

- 各エージェントに渡す道具の定義(メッセージを送る・責任者に聞く・PR を開く)
- チケットごとの作業場所(git worktree)の割り当て
- 起動 1 回ごとの予算と回数の上限
- 役割ごとに渡す情報の絞り込み(レビューには差分とチケットだけ)

## 結果

- エージェントのループの改善はハーネス側の進歩をそのまま受け取れる。
- ハーネスを差し替えられる部品として扱う必要がある([ADR-0012](0012-pluggable-harness.md))。

## 検討した別案

- **ループまで自作する**: 自由度は上がるが、ハーネスの進歩に追いつく保守が重い。
