# ADR-0003: データの元はローカルの SQLite に置き、GitHub には結果を書く

- 状態: 承認
- 日付: 2026-11-07

## 背景

チケット・受信箱・判断・効率の記録を一か所で持ちたい。差分や CI の詳細は GitHub が持っている。

## 決定

- データの元はローカルの SQLite に置く。チケットも Kuramoto の DB を元にする(GitHub issue は後から取り込み元として足せる)。
- PR・コメント・レビューは結果として GitHub に書く。
- GitHub が持っているもの(差分・CI の詳細・PR の本文)は DB に持たず、番号と取得時刻付きの写しだけを置く。

## 結果

- 画面と集計は DB だけを読めばよい。
- 同じものを 2 か所に持たないので、食い違いが起きにくい。写しには取得時刻を付け、古さが分かるようにする。

## 検討した別案

- **GitHub issue を元にする**: 既存の仕組みと相性は良いが、チャットで作ったチケットをボードにすぐ載せる体験や、受信箱との一体化が難しい。
