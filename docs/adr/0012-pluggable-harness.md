# ADR-0012: ハーネスは差し替え口を作り、最初は Claude Agent SDK だけ載せる

- 状態: 承認
- 日付: 2026-11-07

## 背景

バックエンドで動くコーディングエージェントを変えられるようにしたい。

## 決定

- 役割ごとにハーネスを選べる作りにする。Kuramoto がハーネスに求めるのは次の 5 つ。
  1. 作業場所を指定して、人が見ていなくても動かせる
  2. セッションを再開できる
  3. Kuramoto の道具を MCP で渡せる
  4. 使ったトークンやコストを返せる
  5. 予算や時間の上限で止められる
- 最初に載せるのは Claude Agent SDK だけ。他は使う場面が出てから足す。

## 結果

- レビューを別のエージェントにするなど、ハーネスの違いも比べるつまみになる。
- 条件を満たさないハーネスでは一部の機能(持ち主の再開など)が落ちる。画面にできること・できないことを出す。

## 検討した別案

- **差し替え先を最初から複数作る**: 使われない部品の保守が増える。
