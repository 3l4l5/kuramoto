# ADR-0045: メンバーとの会話は member_chat で起こし、今のチケットのセッションで答え、担当・工程は変えない

- 状態: 提案
- 日付: 2026-11-14
- チケット: #10

## 背景

責任者がチケットの途中でメンバーに「今どうなっている」「ここはこうして」と伝えたいとき、リーダーとのチャットを経由するしかなく、メンバーの文脈(今のチケットの会話)が使えなかった。かといって、メンバーに直接話しかけられるようにすると、伝えたことで担当や工程が動いて流れ(ADR-0044)が乱れる。

## 決定

- 責任者がメンバーに話しかけると、受信箱の `member_chat` で起こし、**今のチケットのセッションで答える**(終業中も取り出せる)。
- 会話は `member_messages` に残す。伝えたことは**チケットのメモ**(`ticket_notes` の `kind='member'`)に書き足す。**担当・工程は変えない**。
- メンバーにとって新しい仕事は、`hand_to_lead` でリーダーの受信箱(チャット)に回す。そのときはメモに書かない(仕事の入口はリーダーの交通整理のまま)。
- 起動は `ticket_id` を持たず、`about_ticket_id` でひも付ける(1 チケット 1 起動の決めを邪魔しない)。メンバーが起動中なら、終わるまで待つ。
- API は `GET /members/:id/now`(今していること)・`GET`/`POST /members/:id/chat`。画面はオフィスのメンバーを押して開く引き出し(ADR-0055)。
- 終わった(done・dropped)チケットに話しかけたときの扱いは ADR-0046。

## 結果

- 責任者は、メンバーの手元の文脈のまま、聞く・伝えることができる。
- 伝えたことがメモに残るので、次の担当・レビュアーの起動でも読まれる。
- 新しい仕事はリーダーを通るので、ADR-0024(同じ場所を触るチケットは同時に開発しない)などの交通整理を外れない。

## 検討した別案

- **リーダーのチャットだけで済ませる**: メンバーの文脈が無く、リーダーが取り次ぐことになる。
- **話しかけたら担当・工程を動かせる**: 流れの外から工程が動き、種類ごとの流れ・merge の確かめが崩れる。
- **話しかけるたびに新しいセッションを作る**: 今のチケットの文脈が無くなる。
